Ombre Brain 脱水模型
Ombre Brain 自动起名/摘要压缩 + attunement 用户画像检测共用这一个模型，跟主聊天用的模型是两码事。复用上面填的 API 端点+Key 获取列表。保存后立即热更新生效；但服务器那边设了环境变量优先，如果哪天 OB 服务重启后又变回了旧模型，重新点一次保存即可。
判官模型（心潮互动分类）
心潮"判官"：garden 每轮互动交给这个独立模型分到正确维度（affection/companionship/intimacy/conflict…10 类），避免现在一律按 sharing 上报、把 possess/monitor/crave 养在恒高位。留空 = 判官关闭，行为与今天完全一致（每轮 sharing）；配了才激活。复用上方端点+Key、只换模型名，建议挑便宜的。⚠️ 先手动跑 migration_20（ai_config 加 judge_model 列）再填，否则整条 ai_config 同步会被 PostgREST 拒掉。填了先存库不生效，等 garden 端判官（计划 P2/P3）上线才算数。
AI 工具集
各工具集独立开关，默认全关。开关状态是聊天请求的一部分：默认全关时与暖手宝/私人时间共用同一条缓存前缀；打开某工具 = 该聊天用独立的工具前缀（首次重建一次缓存，正常现象）。
笔友墙（beacon）
开启后AI可在聊天中自主调用 beacon 笔友墙工具（看墙/贴卡片/写信），需端点支持 tools 参数转发。
花园完整工具集（MCP）
启用花园完整工具集
开启后AI可使用花园完整 MCP 工具集（需先填 token 并点击"获取工具列表"成功后才会生效）。token 与工具集只保存在本机浏览器里。
4399小游戏（MCP）
启用4399工具集
开启后AI可在聊天中玩 CEDAR TOY 上的小游戏。主聊天/wake/暖手宝的 4399 身份由服务器配置（.env 的 CEDAR_TOY_TOKEN，无需在此填写）；此处的 token 与工具列表仅影响副聊天直连。
涩涩大富翁（MCP）
开启后AI可在聊天中陪你玩涩涩大富翁（官方托管 MCP 实例，无需 token）。默认关闭。
读书角
开启后AI可在聊天中查看/点评读书角的新章节（bookclub_chapters/read/comments/comment）。需后端已配置书房联动才会真正挂载工具。

自动唤醒平均间隔
单位分钟，平均值，实际忽疏忽密；范围 10–480，默认 30。
私人时间工具调用轮数上限
私人时间一次最多连续调用几轮工具（不影响正常聊天）；范围 2–24，默认 12。留空/清零会自动回落默认值。
唤醒提示词模板
留空 = 用后端内置默认提示词；填了就整段覆盖。可用占位符：{ago}（"ao上次说话是X前。"这句，没有历史消息时自动为空）、{tools_hint}（工具引导句，没挂工具时自动为空）。修改后首次唤醒会重建缓存（正常现象，不用管）。
强制刷新
怀疑改完代码没生效、卡在旧版本时点这个。会清掉页面缓存并绕开缓存重新拉取最新版本，不会影响已保存的数据。iOS 上如果是"添加到主屏幕"的图标，点完仍不生效的话需要删除图标重新添加。「以云端为准」会把云端聊天记录直接拉下来覆盖本设备的本地记录——本机没同步上去的内容会丢，仅在确认云端才是正确版本时使用。
数据备份
导出会把聊天记录、记忆、副聊天、计划、日记、设定和API配置全部打包成一个文件。换设备或清缓存前记得导出，导入会覆盖当前所有数据。
